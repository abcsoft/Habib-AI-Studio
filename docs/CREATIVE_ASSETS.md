# Creative assets

The skincare campaign image was generated with the built-in imagegen tool, then saved to the project and converted to a 1200px WebP for web delivery. The original tool artifact remains in the local Codex generated-image library. No provider key was needed for this build-time asset. This does not configure the application's runtime image API.

Final web asset: `public/showcase/bloom.webp`. Original project artifact: `public/showcase/bloom.png`. Generated fictional brand: Bloom Skincare. The result was visually inspected for product realism, composition and label accuracy.

## Final generation prompt

Use case: product-mockup. Asset type: hero campaign image for Habib AI Studio creative SaaS, also a seeded skincare advertising example. Create a luxury editorial product photograph of one frosted pale peach cylindrical serum bottle with a matte ivory pump, standing on pale pink curved stone plinths against a warm blush studio backdrop. Exact bottle text, small refined dark serif: 'bloom' and below 'DAILY GLOW' and '30 ml'. A soft translucent apricot glass sphere nearby, a dramatic curved shadow sweeping from the top left, warm morning side light, tactile paper and stone grain, highly realistic fine detail. Generous negative space in upper third for later HTML overlay typography. Wide landscape 3:2 composition with bottle center-right, luxurious premium magazine art direction. No watermark, no UI, no additional text, no clutter. This is a fictional demo skincare brand.
