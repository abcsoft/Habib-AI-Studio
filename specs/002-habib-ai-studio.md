# Habib AI Studio

Founders need an entire campaign, from brand context to copy and visuals, in one workspace. Build branded marketing, a public offline demo, authenticated projects and brand kits, structured Claude campaign packages, independent image rendering, saved campaigns, exports, and usage history.

Create projects and brands first; select a goal and generate strategy, hooks, headlines, copy, concepts, brief, visual direction, and image prompts. Render an image separately and save the campaign. Provider failures receive compensating refunds; retrying a request ID never charges twice. Every authenticated read and mutation checks ownership.

Add projects, brand_kits, campaigns, creative_assets and studio_runs with usage, provider request IDs, prompt version, latency and refund metadata. Preserve existing ledger and Stripe paths. Use spendCredits/refundCredits with run IDs. Pricing keeps starter amounts: 10 welcome credits, $9/200 credits, $29/1,000 credits. Campaign packages cost 3 credits; images cost 1.

Verify schemas, provider requests and failure cases, tenant isolation, retry/refund behavior, migrations, ledger invariants, signup, complete demo and authenticated workflows, responsive UI, lint, typecheck, unit tests and production build. Live providers and Stripe need operator credentials before launch.
